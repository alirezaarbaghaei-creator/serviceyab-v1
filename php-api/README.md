# سرویس‌یاب PHP API — راهنمای نصب و استقرار

بک‌اند فاز اول سامانه سرویس‌یاب (پیوست شماره ۱ قرارداد): ثبت‌نام، پروفایل متقاضی، آزمون آنلاین چهارگزینه‌ای و پنل مدیریت.

## فایل‌ها

| فایل | کاربرد |
|------|--------|
| `config.php` | تنظیمات اتصال به دیتابیس (نام دیتابیس، کاربری، رمز) |
| `index.php` | فایل اصلی API — تمام درخواست‌ها اینجا پردازش می‌شوند |
| `schema.sql` | اسکیمای کامل دیتابیس (اختیاری؛ جداول به‌صورت خودکار هم ساخته می‌شوند) |
| `.htaccess` | تنظیمات سرور برای CORS و امنیت |

## مراحل آپلود

1. وارد پنل هاستینگ خود شوید (cPanel، DirectAdmin و ...).
2. به File Manager بروید و به پوشه `public_html` بروید.
3. یک پوشه جدید به نام `api` بسازید.
4. تمام فایل‌های این پوشه (`config.php`، `index.php`، `schema.sql`، `.htaccess`) را داخل `public_html/api/` آپلود کنید.
5. نتیجه: آدرس API شما خواهد شد:
   ```
   https://yourdomain.com/api/index.php
   ```

## تنظیم دیتابیس

1. در پنل هاست، یک دیتابیس MySQL جدید بسازید (مثلاً `serviceyab`).
2. یک کاربر برای دیتابیس بسازید و رمز عبور قوی انتخاب کنید.
3. کاربر را به دیتابیس متصل کنید (Add User to Database) و **All Privileges** را بدهید.
4. فایل `config.php` را باز کنید و مقادیر زیر را تغییر دهید:

```php
'db_host' => 'localhost',              // معمولاً همین می‌ماند
'db_name' => 'serviceyab',             // نام دیتابیس
'db_user' => 'serviceyab',             // نام کاربری دیتابیس
'db_pass' => 'CHANGE_THIS_PASSWORD',   // رمز عبور دیتابیس
```

5. فایل `config.php` را ذخیره و دوباره آپلود کنید.

## ساخت خودکار جداول

نیازی به دستی ساخت جدول نیست. اولین باری که API فراخوانی شود، تمام جداول (`sy_users`، `sy_profiles`، `sy_questions`، `sy_exams`، `sy_attempts`، ...) به‌طور خودکار ساخته می‌شوند. در صورت تمایل، `schema.sql` را هم می‌توانید از phpMyAdmin اجرا کنید.

یک حساب مدیر پیش‌فرض هم ساخته می‌شود:
- **شماره موبایل:** `09120000000`
- **رمز عبور:** `admin123`

> ⚠️ **بلافاصله پس از اولین ورود، رمز عبور مدیر را تغییر دهید.**

## راه‌اندازی اولیه پنل مدیریت (ماده ۱۱ و ۱۲ قرارداد)

پس از استقرار، با حساب مدیر وارد شوید و به ترتیب:

1. **پنل پیامک:** کلید API و کد الگوی سرویس پیامکی (ایران‌پیامک) را وارد کنید تا کد یک‌بارمصرف ورود با پیامک ارسال شود. تا زمانی که خالی باشد، کد در پاسخ توسعه برگردانده می‌شود (فقط برای تست).
2. **سؤالات آزمون:** حداکثر ۵۰ سؤال چهارگزینه‌ای ثبت کنید (ماده ۷-۲). برای هر سؤال، گزینه صحیح را مشخص و آن را «فعال» کنید.
3. **تنظیمات آزمون:** عنوان، مدت زمان، تعداد سؤالات ارائه‌شده، حدنصاب قبولی، حداکثر دفعات شرکت و سیاست نمایش نمره به کاربر را تنظیم کنید و در انتها «آزمون فعال باشد» را روشن کنید.
4. **متقاضیان:** فهرست متقاضیان را با جست‌وجو و فیلتر (شهر/وضعیت/آزمون) ببینید، پرونده هر فرد را باز کنید، وضعیت بررسی (جدید/در حال بررسی/تأیید اولیه/ردشده) را تغییر دهید و از دکمه «خروجی CSV» فایل اکسل‌سازگار بگیرید (ماده ۸-۷).
5. **مدیران:** در صورت نیاز، حساب مدیر دیگری بسازید (ماده ۸-۱).

## اتصال وب‌اپلیکیشن

آدرس API به‌صورت پیش‌فرض از متغیر محیطی `VITE_API_URL` هنگام بیلد خوانده می‌شود. روش دیگر: آدرس API در حافظه مرورگر/اپ ذخیره می‌شود (`serviceyab_api_url`) و از پنل مدیریت قابل تغییر است.

## پیشنیازها

- PHP 7.4 یا بالاتر
- اکستنشن `pdo_mysql` فعال باشد
- اکستنشن `curl` فعال باشد (برای ارسال پیامک)
