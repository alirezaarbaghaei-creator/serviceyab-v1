# PHP API قدیمی Kateb — منسوخ

> **هشدار: این API متعلق به محصول قبلی Kateb است و بخشی از سرویس‌یاب نیست. آن را روی سرور سرویس‌یاب نصب یا اجرا نکنید.**

این پوشه صرفاً برای ممیزی و استخراج احتمالی اجزای عمومی نگه داشته شده است. هیچ‌یک از موارد زیر برای استقرار سرویس‌یاب تأیید نشده‌اند:

- ساختار دیتابیس و جداول
- endpointها و قرارداد درخواست/پاسخ
- احراز هویت و نشست‌ها
- حساب مدیر پیش‌فرض و تنظیمات اولیه
- تنظیمات CORS و امنیت

## اقدامات لازم پیش از استفاده مجدد

1. طراحی قرارداد API سرویس‌یاب و مدل نقش‌ها باید مستقل انجام شود.
2. احراز هویت، مجوزدهی و کنترل مالکیت داده باید بازطراحی و تست شوند.
3. هیچ رمز، حساب پیش‌فرض یا کلید قدیمی نباید استفاده شود.
4. در صورت انتخاب PHP برای Backend جدید، پیاده‌سازی در مسیر و ساختار تازه انجام شود؛ این API قدیمی را مبنا قرار ندهید.

تا زمان تصمیم معماری، این پوشه deprecated است.
