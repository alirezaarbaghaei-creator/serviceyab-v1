# سرویس‌یاب | شرکت ره‌آورد الکترونیک

سامانه مدیریت و پیگیری خدمات پس از فروش، درخواست‌های سرویس و شبکه نمایندگان شرکت ره‌آورد الکترونیک.

> وضعیت: مرحله آماده‌سازی و بازطراحی پایه  
> شاخه توسعه: `serviceyab-rebuild`

## اهداف محصول

- ثبت و پیگیری درخواست‌های خدمات مشتریان
- مدیریت مشتریان، محصولات و سوابق خدمات
- مدیریت نمایندگی‌ها، تکنسین‌ها و مناطق تحت پوشش
- ارجاع درخواست‌ها و پایش چرخه انجام خدمت
- پنل مدیریت مرکزی و پنل عملیاتی نمایندگان
- گزارش‌گیری از عملکرد شبکه خدمات

## فناوری‌های پایه

React، TypeScript، Vite و Capacitor در حال ارزیابی برای حفظ هستند. انتخاب نهایی معماری Backend، پایگاه داده و مدل احراز هویت پس از ممیزی وابستگی‌ها و تثبیت دامنه فاز اول انجام می‌شود.

## وضعیت مهاجرت

این شاخه از نسخه قبلی مخزن منشعب شده است. کدها و داده‌های اختصاصی محصول قبلی باید به‌صورت مرحله‌ای و پس از بررسی وابستگی‌ها حذف یا جایگزین شوند. شاخه `main` نسخه مرجع اولیه را حفظ می‌کند.

- [نقشه راه بازطراحی](docs/MIGRATION_PLAN.md)
- [فهرست اولیه اجزای میراثی](docs/LEGACY_KATEB_INVENTORY.md)

## توسعه

تا پیش از تکمیل بازطراحی، اجرای نسخه فعلی به معنی آماده بودن محصول سرویس‌یاب نیست. از داده‌ها، کلیدها یا حساب‌های پیش‌فرض موجود در نسخه قبلی در محیط عملیاتی استفاده نکنید.
