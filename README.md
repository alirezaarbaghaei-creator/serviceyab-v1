# سرویس‌یاب (ServiceYab) — فاز اول

سامانه ارزیابی اولیه متقاضیان همکاری با شبکه تخصصی تعمیرات بردهای الکترونیکی.

این ریپو از تبدیل کدبیس قبلی (کاتب) به محصول سرویس‌یاب بر اساس **پیوست شماره ۱ قرارداد** ایجاد شده است (شاخه `serviceyab-conversion`).

## امکانات فاز اول (مطابق شرح خدمات)

- **وب‌سایت عمومی:** صفحه فرود معرفی (اهداف و مزایا، مراحل ثبت‌نام، سؤالات متداول)
- **ثبت‌نام و ورود:** شماره موبایل + کد یک‌بارمصرف پیامکی یا رمز عبور (ماده ۵)
- **پروفایل متقاضی:** فرم اطلاعات فردی/تماس، آموزشی، تخصصی و توضیحات تکمیلی (ماده ۵-۴)
- **آزمون آنلاین چهارگزینه‌ای:** دستورالعمل، تایمر سمت سرور، ذخیره تدریجی پاسخ‌ها، تصحیح خودکار با کلید پاسخ، سقف ۵۰ سؤال و سیاست تعداد دفعات (ماده ۷)
- **پنل کاربری متقاضی:** داشبورد، وضعیت تکمیل پروفایل، وضعیت آزمون، وضعیت درخواست و راهنمای اولیه (ماده ۶)
- **پنل مدیریت:** آمارهای پایه، فهرست متقاضیان با جست‌وجو/فیلتر (شهر، وضعیت بررسی، وضعیت آزمون)، پرونده اختصاصی هر متقاضی، تغییر وضعیت (جدید/در حال بررسی/تأیید اولیه/ردشده)، مدیریت سؤالات و تنظیمات آزمون، خروجی CSV سازگار با اکسل (ماده ۸)
- **امنیت:** تصحیح آزمون و اعتبارسنجی سمت سرور، جداسازی دسترسی کاربر عادی از مدیریتی، شماره موبایل به‌عنوان شناسه (ماده ۱۰)

## معماری

| بخش | فناوری |
|------|--------|
| فرانت | React 19 + TypeScript + Vite + Zustand + Tailwind (RTL، فونت وزیرمتن) |
| بک‌اند | PHP API تک‌اندپوینت + MySQL (پوشه `php-api/`) |
| موبایل | Capacitor (اندروید) — نام اپ سرویس‌یاب؛ شناسه بسته `com.kateb.app` موقتاً حفظ شده است |
| اعلان‌ها | FCM (Capacitor Push) + پرکردن خودکار کد پیامکی روی اندروید |

## توسعه محلی

```bash
npm install
npm run dev          # وب
npm run build        # بیلد tsc + vite
npm run cap:sync     # سینک اندروید (نیازمند بیلد)
```

آدرس API با متغیر محیطی `VITE_API_URL` تنظیم می‌شود (پیش‌فرض: ذخیره‌شده در حافظه دستگاه از پنل مدیریت).

## استقرار بک‌اند

راهنمای کامل در [`php-api/README.md`](php-api/README.md): آپلود در هاست اشتراکی، تنظیم دیتابیس، ساخت خودکار جداول و راه‌اندازی اولیه پنل مدیریت.

## چک‌لیست پذیرش (ماده ۱۳)

1. صفحات عمومی (فرود) در دسترس است
2. ثبت‌نام/ورود با موبایل و کد یک‌بارمصرف یا رمز عبور
3. اطلاعات پروفایل ثبت و ذخیره می‌شود و قابل ویرایش است
4. سؤالات آزمون به‌درستی نمایش داده می‌شوند
5. پاسخ‌ها ثبت و نمره مطابق کلید سمت سرور محاسبه می‌شود
6. نتیجه آزمون در پرونده متقاضی (پنل مدیریت) قابل مشاهده است
7. مدیر فهرست متقاضیان را با جست‌وجو و فیلتر می‌بیند
8. مدیر پرونده را مشاهده و وضعیت را تغییر می‌دهد
9. خروجی CSV تولید می‌شود
10. صفحات در موبایل و دسکتاپ واکنش‌گرا هستند
11. استقرار روی زیرساخت مورد توافق + دسترسی مدیریتی و آموزش مقدماتی

## نکته‌های باقی‌مانده برای فاز بعد

- لوگوی رسمی و آیکون‌های PNG/اسپلش پس از دریافت هویت بصری از کارفرما تعویض می‌شود (فعلاً آیکون موقت)
- شناسه بسته اندروید (`com.kateb.app`)، اسکیم `kateb://` و دامنه API پس از توافق روی هویت نهایی قابل تغییر است
- محتوای متنی صفحات عمومی و سؤالات آزمون باید توسط کارفرما تأیید و نهایی شود (ماده ۴ و ۱۶)
- سرویس پیامک باید توسط کارفرما تأمین اعتبار شود (ماده ۵-۱)
