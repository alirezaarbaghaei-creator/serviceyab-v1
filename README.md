# سرویس‌یاب | شرکت ره‌آورد الکترونیک

نسخه وب و وب‌اپلیکیشن سامانه جذب و ارزیابی اولیه متقاضیان همکاری در شبکه تخصصی تعمیرات بردهای الکترونیکی.

> وضعیت: بازطراحی پایه بر اساس پیوست شماره یک قرارداد فاز اول  
> شاخه توسعه: `serviceyab-rebuild`

## محدوده فاز اول

- وب‌سایت عمومی معرفی سرویس‌یاب، اهداف، مزایا، مراحل همکاری و پرسش‌های متداول
- ثبت‌نام و ورود با روش احراز هویت نهایی‌شده
- حساب کاربری و پرونده فردی، آموزشی و تخصصی متقاضی
- آزمون آنلاین چهارگزینه‌ای با بانک حداکثر ۵۰ سؤال
- ثبت پاسخ‌ها و محاسبه خودکار نمره
- پنل متقاضی برای تکمیل پروفایل، آزمون و مشاهده وضعیت
- پنل مدیریت پایه: داشبورد، جست‌وجو، فیلتر، پرونده، وضعیت بررسی و خروجی CSV
- استقرار، آزمایش، آموزش مقدماتی و رفع ایرادهای داخل محدوده

## خارج از محدوده فاز اول

اپلیکیشن مستقل Android/iOS، مدیریت سفارش تعمیر، ارجاع مأموریت، مدیریت عملیاتی نمایندگان، تیکتینگ، چت، تسویه مالی و گزارش تحلیلی پیشرفته در این فاز پیاده‌سازی نمی‌شوند. معماری باید امکان توسعه بعدی را حفظ کند، اما این موارد تعهد اجرایی فعلی نیستند.

## فناوری

پایه رابط کاربری موجود React، TypeScript و Vite است. معماری Backend و احراز هویت در حال بازطراحی است. migration جدید پایگاه داده برای Supabase Auth و سیاست‌های RLS محدود طراحی شده است؛ استقرار آن باید روی پروژه Supabase مستقل سرویس‌یاب انجام شود، نه دیتابیس قدیمی Kateb.

## راه‌اندازی

فایل `.env.example` را به `.env.local` کپی و مقادیر محیطی پروژه جدید را تنظیم کنید. هیچ کلید سرویس‌نقش، رمز مدیر یا Secret نباید در کد سمت مرورگر قرار گیرد.

**هشدار:** تا تکمیل جداسازی دامنه قبلی، اجرای فعلی مخزن به معنی آماده‌بودن سامانه سرویس‌یاب نیست. migrationهای قدیمی و API کاتب برای استقرار سرویس‌یاب معتبر نیستند.
