# فهرست اجزای میراثی Kateb

این فهرست بر اساس درخت مخزن و بررسی نقاط ورود تهیه شده است. حذف باید پس از جایگزینی مصرف‌کننده‌ها انجام شود.

## حذف از محصول فاز اول

- نامه‌نگاری و تولید متن: `Templates`, `ChatFlow`, `Preview`, `Archive`, `Drafts`, `Discovery`, ویرایشگر Tiptap و سرویس‌های AI
- مدیریت شخصی/تقویم/وظایف Kateb: `ManagerPage`، store و سرویس‌های manager
- اشتراک و درآمدزایی: پلن‌ها، سکه‌ها، درگاه زرین‌پال، پرداخت و Cafe Bazaar
- خروجی‌های Word/PDF/print اختصاصی نامه‌ها
- Edge Functionهای `kateb-api` و `ai-proxy` مگر آنکه پس از بازطراحی نیاز مستقلی تأیید شود
- PHP API و schema اختصاصی Kateb
- migrationهای Kateb و custom auth؛ دیتابیس سرویس‌یاب باید مستقل باشد

## قابل استفاده پس از بازبینی

- React، TypeScript، Vite، Tailwind و ساختار عمومی build
- اجزای عمومی فرم، modal، notification، layout و validation
- فونت فارسی، RTL و ابزار تاریخ شمسی
- helperهای ذخیره‌سازی امن و diagnostics در صورت نیاز واقعی
- workflowهای CI پس از حذف fallbackهای رمز و نام‌های Kateb
- قابلیت‌های PWA عمومی، پس از اصلاح برند و cache

## خارج از محدوده فاز اول

- Capacitor و پوشه Android به‌عنوان اپ مستقل تحویلی؛ نگهداری فعلی آن‌ها ضروری نیست.
- اعلان push پیشرفته، چت، تیکتینگ، سفارش تعمیر و پنل عملیاتی نمایندگان

## هشدار امنیتی

migrationهای قبلی شامل سیاست‌های RLS باز و تنظیمات/حساب پیش‌فرض Kateb بوده‌اند. این migrationها نباید روی دیتابیس سرویس‌یاب اجرا شوند. حذف فایل از شاخه جدید، تاریخچه Git یا دیتابیس قبلاً مستقرشده را پاک نمی‌کند. Secret افشاشده باید در سرویس مربوطه تعویض شود.
